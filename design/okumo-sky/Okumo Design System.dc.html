07

Uygulama

İki dosya değişiyor: src/app/globals.css (mavi ailesi — mevcut hiçbir token değişmiyor; dark blok iki yerde: .dark ve prefers-color-scheme media query) ve CozyButton.tsx (yeni info varyantı).

:root {
  /* … mevcut tokenlar aynen kalır … */
  --sky-50:   #eaf3f7;
  --sky-soft: #d6e8f0;
  --sky-light:#7fb9d1;
  --sky:      #4f93b0;
  --sky-deep: #3a7691;
}

.dark {
  --sky-50:   #1d2a31;
  --sky-soft: #2b3d47;
  --sky-light:#5f9cb5;
  --sky:      #8fc7dc;
  --sky-deep: #b6dcea;
}

/* globals.css'te dark tokenlar iki yerde tanımlı —
   media query bloğuna da AYNI değerler eklenmeli: */
@media (prefers-color-scheme: dark) {
  :root:not(.light) {
    --sky-50:   #1d2a31;
    --sky-soft: #2b3d47;
    --sky-light:#5f9cb5;
    --sky:      #8fc7dc;
    --sky-deep: #b6dcea;
  }
}

@theme inline {
  --color-sky-50:    var(--sky-50);
  --color-sky-soft:  var(--sky-soft);
  --color-sky-light: var(--sky-light);
  --color-sky:       var(--sky);
  --color-sky-deep:  var(--sky-deep);
}

/* prose-cozy (LLM markdown) — link rengi mavi rolüne göre: */
.prose-cozy a {
  color: var(--sky-deep);
  text-decoration: underline;
  text-underline-offset: 2px;
}

type Variant = "primary" | "ghost" | "soft" | "info";
