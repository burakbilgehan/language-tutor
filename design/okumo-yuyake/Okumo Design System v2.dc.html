07

Uygulama · v1 → v2 göçü

Bu kez tokenlar değişiyor. Göç haritası: --moss kaldırılır → tüm kullanımlar --indigo; --sky-* ailesi kaldırılır → --indigo-*; --gold → --amber. Dark blok iki yerde güncellenir: .dark ve prefers-color-scheme media query.

:root {
  --background:  #f6ead2;
  --surface:     #fdf6e7;
  --surface-2:   #f4e5cb;
  --ink:         #251e18;
  --ink-soft:    #6e5b45;
  --accent:      #c14a1d;   /* eski #c4643b */
  --accent-soft: #f2d8c4;
  --danger:      #8f3116;
  --indigo-soft: #e4ebf3;   /* --sky-* ailesinin yerine */
  --indigo-mid:  #41608c;
  --indigo:      #2f4a70;
  --indigo-deep: #24395a;
  --amber:       #e8a13c;   /* eski --gold */
  --amber-text:  #b07414;
  --locked:      #d9c6a4;
  /* --moss, --moss-soft: KALDIRILDI → indigo kullan */
}

.dark {
  --background:  #1c1712;
  --surface:     #282019;
  --surface-2:   #322a20;
  --ink:         #f0e4cd;
  --ink-soft:    #d9c9ab;
  --accent:      #e07b3f;
  --accent-soft: #3a2c20;
  --danger:      #d96a4a;
  --indigo-soft: #222c3e;
  --indigo-mid:  #5f7db0;
  --indigo:      #8fa9cf;   /* gece aydınlanır */
  --indigo-deep: #c7d4e8;
  --amber:       #e8a13c;
  --amber-text:  #e8a13c;
  --locked:      #4a3f30;
}
/* AYNI değerler prefers-color-scheme bloğuna da: */
@media (prefers-color-scheme: dark) {
  :root:not(.light) { /* … .dark ile birebir … */ }
}

@theme inline {
  --color-indigo-soft: var(--indigo-soft);
  --color-indigo-mid:  var(--indigo-mid);
  --color-indigo:      var(--indigo);
  --color-indigo-deep: var(--indigo-deep);
  --color-amber:       var(--amber);
  --color-amber-text:  var(--amber-text);
  /* --color-sky-*, --color-moss*: SİL */
}

.prose-cozy a {
  color: var(--indigo);
  text-decoration: underline;
  text-underline-offset: 2px;
}

CozyButton.tsx — info varyantı artık indigo:

type Variant = "primary" | "ghost" | "soft" | "info";

const styles: Record<Variant, string> = {
  /* primary/ghost/soft aynen; renkleri token'dan gelir */
  info: "bg-indigo text-surface hover:brightness-110 shadow-cozy disabled:opacity-40",
}

Kod tarama listesi: bg-moss, text-moss, bg-sky* sınıfları repo genelinde aranıp indigo karşılıklarıyla değiştirilir; başarı işaretleri (✓ düğümleri, ilerleme) indigoya, XP/seri amber'e bağlanır.
